# Architecture Decision Records

This folder contains Architecture Decision Records (ADRs) for the
web-request-wrapper module.

ADRs follow the format established by the ADR community:
https://github.com/architecture-decision-record/architecture-decision-record

Each record documents:
- The context and problem being addressed
- The decision made
- The rationale, including RFC or specification references where applicable
- The consequences and any deferred follow-up
